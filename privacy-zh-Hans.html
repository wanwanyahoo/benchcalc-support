BenchCalc 可以离线使用。应用没有账户系统、广告、跟踪、分析服务或开发者运营的数据服务器。

更新于 2026 年 11 月 9 日。本政策说明 BenchCalc iPhone 与 iPad 应用的数据处理方式，支持网站与公开问题反馈页面另见下文。

应用内保存的数据

计算结果、输入、历史、记忆位、设置、项目、报价、笔记及附件保存在设备上的应用本地存储中。BenchCalc 不会自动将这些记录上传给发布者，也不会将其同步至云端账户。

仅当你通过系统照片或文件选择器单独选取内容时，应用才会添加相应附件。应用不请求广泛读取照片图库的权限。所选附件内容的副本会成为本地记录本及完整 JSON 备份的一部分。

导出及你选择的服务

当你导出结果、PDF、CSV、附件或 JSON 备份时，所选内容会交给你选择的目标。完整备份包含原始附件与项目文字。BenchCalc 不为导出文件额外设置密码或加密。

「文件」、iCloud 云盘、其他存储提供商和分享目标可能根据你的操作及各自政策通过网络传输数据。这些操作由你主动发起，BenchCalc 不提供自动云同步。设备系统备份与诊断信息遵循你的 Apple 设备设置。

保留与删除

本地记录会保留，直到你删除记录、通过导入备份替换记录本，或移除应用本地数据。系统可能按其设置保留备份副本。移除项目会删除报价条目、独立笔记和附件，但计算记录与计算备注仍保留在历史中，可另行删除。

预览及分享时可能生成临时本地文件，并保留至系统清理临时存储。在 BenchCalc 中删除记录不会撤回已经导出、分享或保存到其他服务的文件。

应用数据收集与跟踪

BenchCalc 不会向发布者发送计算内容、照片、文件、设备标识符、位置或使用分析信息。应用不出售数据，不跨应用或网站跟踪用户，也不包含广告 SDK。App Store 购买和 Apple 系统服务由 Apple 依据其政策处理。

App Store 购买

3.1 及以上版本的可选零费用试用、专业版买断和恢复购买由 Apple 处理。BenchCalc 验证 StoreKit 交易，并在仅限本设备的钥匙串中保存应用专用的购买标识、商品标识、日期和权限状态，以支持离线使用及保留旧版付费用户权益。这些记录不会发送至开发者服务器。恢复购买通过 Apple 服务使用你的 Apple 账户，BenchCalc 不会收到你的 Apple 账户密码或银行卡信息。购买权限的钥匙串记录可能在重新安装后保留；移除应用不会取消购买或发起退款。

支持网站与反馈

本支持网站托管于 GitHub Pages。GitHub 会出于安全目的记录访问者的 IP 地址，具体见 GitHub Pages 说明及 GitHub 隐私声明。这些静态页面未添加分析脚本、广告或跟踪像素。

若你主动通过 公开问题反馈页面联系支持，你发布的内容、GitHub 资料及上传的附件由 GitHub 处理，且公开可见。发布者使用你主动提供的信息答复请求及调查问题。请勿发布私人项目数据、完整备份或个人照片。GitHub 平台的数据保留及账户设置由其管理。

更新与联系

若应用的数据处理方式发生变化，本政策也会更新。隐私问题可通过 支持反馈页面提出。应用不会自动发送支持请求或附加你的记录。
