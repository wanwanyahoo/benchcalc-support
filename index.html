Construction calculations, estimates, and project records for iPhone and iPad. One purchase includes every tool, with no subscription or in-app purchases.

Using calculations

Choose a tool in Workbench or Professional, enter dimensions, and calculate. You can use metric units, feet and inches, or fractions such as 6' 3 1/2". An explicit unit suffix takes priority over the selected default unit.

In Expression, write a complete calculation such as (3m + 50cm) / 2. Put a unit on each dimension. Choose degrees or radians for trigonometry. Approximate results are marked ≈.

Tap a history entry to restore its inputs. Editing a saved calculation retains its project and note. Memory registers store results for later use.

Estimates and projects

Open Projects to create a project or use Save to project on a result. Add material or labor rows and enter the quantity, unit, and unit price. You can also add a calculation result directly to an estimate.

Choose the project's currency and adjustment rates. Material waste is applied first, followed by labor, discount, markup, and tax. Rates are supplied by you. Changing the currency does not convert prices. The final total is rounded to the selected currency's decimal places.

Project notes are independent text records. You can add selected photos and files through the system pickers. Each attachment is limited to 10 MB; all attachments together are limited to 50 MB.

Export and backup

  1. Inside a project, export a quotation or complete report as PDF, or a table as CSV. The optional PDF attachment index lists attachments; it does not embed the original files.
  2. In Projects, choose Export complete JSON backup to include calculations, projects, notes, estimates, and original attachment data.
  3. Use Files to choose a destination, including iCloud Drive if available. Cloud storage is managed by the destination you choose. BenchCalc has no automatic cloud sync.

Importing a JSON backup replaces the whole notebook after validation. Export a copy of your current notebook first if you want to keep it. Invalid imports leave the current notebook unchanged. The app does not add password protection or encryption to exported backups.

Removing data

Swipe a calculation, note, estimate row, or attachment to remove it. Removing a project deletes that project's estimate rows, standalone notes, and attachments. Its calculations and calculation notes remain in history. Deleting an item in the app does not delete copies that you have already exported or shared.

If saving or importing fails

Check device storage and file size. A complete backup must be 80 MB or less. If the saved notebook cannot be read, BenchCalc preserves the original file and blocks changes rather than overwriting it. Keep existing exported backups and contact support before removing the app.

Languages and connectivity

Calculation tools work offline. Opening a cloud file or sending an export can require a connection through the service you select. Some specialized labels and explanations remain in English in some interface languages.

Contact

For questions, bug reports, and feature requests, use the BenchCalc support issue tracker. A GitHub account may be needed to post. Include your app version, device, selected tool, units, inputs, expected result, and actual result.

Issues are public. Remove private project information and do not attach complete backups or personal photos. Share only the details needed to reproduce the problem.
