适用于 iPhone 和 iPad 的施工计算、报价与项目记录。离线现场工具，无订阅。

免费工具、试用与专业版（3.1 及以上版本）

尺寸计算、单位换算、方正与对角线、等距排布等基础工具可免费使用。专业版包含其他施工计算、整式计算、新建项目、报价编辑和专业计算 PDF 导出。

在「Pro」中主动选择零费用的 7 天试用，或一次购买专业版：美国区 US$1.00，其他地区由 Apple 定价，确认前会显示当地价格。试用不会自动转为收费，也没有订阅。7 天后基础工具和已保存记录仍可使用；恢复购买不会重置试用结束时间。

此前已付费下载旧版本的用户，在原始 App Store 购买验证后仍包含全部专业功能。需要时，在「Pro」中用同一 Apple 账户「恢复购买」。3.0 版本采用此前的全功能付费下载方式。激活试用、购买或恢复需要连接 App Store，验证后的权限会在本机缓存以供离线使用。

使用计算工具

在「工作台」或「专业工具」中选择工具，输入尺寸后计算。支持公制、英尺英寸及分数，例如 6' 3 1/2"。显式单位后缀优先于所选默认单位。

在「整式计算」中输入完整算式，例如 (3m + 50cm) / 2。每个尺寸需自带单位。三角函数可选择角度制或弧度制。近似结果会标记 ≈。

点击历史记录可恢复输入。编辑已保存的计算会保留项目关联与备注。记忆位可保存结果供后续使用。

报价与项目

打开「项目」新建项目，或在计算结果中使用「保存到项目」。添加材料或工时条目，输入数量、单位和单价，也可直接将计算结果添加至报价。

在项目中设置货币与调整费率。先计算材料损耗，再合计工时、减免折扣、加价和税额。所有费率由你输入，更改货币不会换算价格。最终总额按所选货币的小数位取整。

项目独立笔记用于保存文字说明。照片和文件通过系统选择器逐项添加，每个附件最多 10 MB，全部附件总量最多 50 MB。

导出与备份

  1. 在项目内导出报价或完整报告 PDF，也可导出 CSV 表格。PDF 可选附件清单仅列出说明，不嵌入原始附件。
  2. 在「项目」中选择「导出完整 JSON 备份」，包含计算、项目、笔记、报价及原始附件数据。
  3. 通过「文件」选择保存位置，可使用已启用的 iCloud 云盘。云端存储由所选服务处理，BenchCalc 不提供自动云同步。

导入 JSON 备份会在通过校验后替换整个记录本。若需保留当前内容，请先导出备份。无效备份不会更改现有记录。BenchCalc 不为导出的备份额外设置密码或加密。

删除数据

滑动计算记录、笔记、报价条目或附件可删除。移除项目会删除该项目的报价、独立笔记及附件；计算记录及其计算备注仍保留在历史中。在应用中删除内容不会删除已经导出或分享的副本。

保存或导入失败时

检查设备存储空间和文件大小。完整备份最多 80 MB。若已保存的记录文件无法读取，BenchCalc 会保留原文件并阻止更改，避免覆盖。请保留已有导出备份，在移除应用前联系支持。

语言与网络

计算工具可以离线使用。打开云端文件或分享导出文件时，所选服务可能需要联网。界面提供 24 种语言选项。

联系支持

使用 BenchCalc 问题反馈页面提交使用问题、错误报告或功能建议；发布反馈可能需要 GitHub 账户。请提供应用版本、设备、所选工具、单位、输入、预期结果及实际结果。

反馈内容公开可见。请移除私人项目信息，不要上传完整备份或个人照片，只提供复现问题所需的内容。
